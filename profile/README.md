# MCCCD District Information Technology Services

Our projects use a shared five-pillar review framework so Infrastructure, Development, Business ERPs, End Point Engineering, CyberSecurity and other affected owners can review code impacting their users, services and support responsibilities.

Start with the [organization review framework](https://github.com/mcccd-IT-Operations/.github/blob/main/README.md), [governance](https://github.com/mcccd-IT-Operations/.github/blob/main/GOVERNANCE.md) and [project catalog](https://github.com/mcccd-IT-Operations/.github/blob/main/README.md#project-catalog). Each independent project has its own repository and approval evidence. Code begins with purpose/context notes and continued section comments explaining what happens and why.

Framework formal adoption and project approvals remain pending where their records say so. A repository or downloadable candidate is not production authorization.
